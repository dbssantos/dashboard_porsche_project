# Porsche Sales Dashboard

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar a organização de dados no Excel, a análise de informações comerciais e a criação de uma dashboard interativa em HTML com apoio de inteligência artificial.

A proposta consiste em explorar uma base de dados de vendas de veículos Porsche por meio de indicadores e visualizações que facilitam a identificação de padrões por modelo, cidade, ano do veículo, método de pagamento e período.

O projeto também considera aspectos de UI/UX, utilizando como referência visual o site oficial da Porsche Brasil e uma paleta de cores em tons de vermelho.

**Status:** projeto de aprendizado — dashboard ainda não publicada em uma URL pública.

## Objetivo

Transformar os dados disponíveis em uma visualização interativa que facilite a exploração das informações e ajude a responder perguntas de negócio relacionadas ao volume de registros, aos modelos e à distribuição geográfica.

## Perguntas de negócio

O desenvolvimento da dashboard foi orientado por três perguntas principais:

**1. Quais são os principais modelos vendidos por cidade?**

Permitir a comparação dos modelos registrados em cada cidade, identificando aqueles com maior frequência na base analisada.

**2. Qual ano-modelo de veículo apresentou maior volume em determinado período?**

Analisar a distribuição dos registros por ano do veículo, considerando o período selecionado nos filtros.

**3. Quais insights sobre os modelos mais vendidos podem ser identificados em cada cidade?**

Explorar os registros por cidade e modelo para observar padrões e diferenças entre as localidades presentes na base.

Essas perguntas orientam a análise dos dados disponíveis no projeto. Os resultados devem ser interpretados considerando as características e limitações da base utilizada, e não como estatísticas oficiais da Porsche.

## Ferramentas e tecnologias

- **Microsoft Excel:** organização e limpeza da base de dados.
- **ChatGPT com Canvas:** criação e refinamento da dashboard por meio de conversas iterativas.
- **HTML:** estrutura da página.
- **CSS:** estilização, layout e identidade visual.
- **JavaScript:** funcionamento dos filtros e atualização dos indicadores e visualizações.

## Prompt original

O prompt utilizado para iniciar a criação da dashboard foi:

> Utilizando o modelo de recurso Canvas, renderize uma dashboard em HTML ao lado.
>
> **Filtros:** modelo, cidade, ano, método de pagamento.
>
> **Perguntas de negócio:** quais os principais modelos vendidos por cidade, qual o ano de modelo de carro que mais saiu em um período, e insight de vendas de carros populares de vendas com bases nos dados em cada cidade.
>
> **UI/UX:** se baseie no site oficial da Porsche Brasil: https://www.porsche.com/brazil/pt/
>
> Quero a paleta de cores no tom vermelho.

## Processo de desenvolvimento

A dashboard foi desenvolvida com o auxílio do ChatGPT utilizando o recurso Canvas. A partir do prompt inicial e da base de dados, o HTML foi refinado por meio de conversas até chegar à versão final do projeto.

O processo envolveu a definição dos filtros, a organização dos indicadores e a construção das visualizações para explorar os dados.

Não foi utilizado um agente com skill específica; o processo descrito foi realizado com ChatGPT e Canvas.

## Tratamento dos dados

Antes de utilizar a base no desenvolvimento da dashboard, foi realizada uma etapa de limpeza e organização dos dados no Excel.

## Funcionalidades da dashboard

A dashboard apresenta recursos para explorar os dados de maneira interativa:

- Filtro por modelo do veículo.
- Filtro por cidade.
- Filtro por ano do veículo.
- Filtro por método de pagamento.
- Seleção de data inicial e final.
- Indicador de volume de registros no recorte selecionado.
- Indicador de receita total registrada.
- Indicador de ticket médio.
- Identificação do modelo com maior frequência.
- Visualização dos modelos com maior volume de registros.
- Análise dos registros por cidade.
- Distribuição por ano do veículo.
- Distribuição por método de pagamento.
- Comparação do modelo líder por cidade.
- Leituras rápidas dos principais destaques do recorte.
- Opção para redefinir os filtros.

Os indicadores são calculados com base nos registros disponíveis e nos filtros selecionados. A receita e o ticket médio dependem dos preços presentes na base.

## Design e UI/UX

A proposta visual foi inspirada no site oficial da Porsche Brasil, com foco em uma apresentação organizada e uma paleta de cores em tons de vermelho.

A interface foi planejada para facilitar a leitura dos indicadores, a comparação entre categorias e a exploração dos dados por meio de filtros.
